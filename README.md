# OdysseyBlue – Greece Travel Website

A travel and tourism website that promotes Greece. Visitors can discover attractions, explore local culture, learn about activities, check transport options and send an enquiry.

## Pages

- Home (index.html): headline, introduction, about Greece, quick facts, 4 reasons to visit, Greek phrase of the day, footer
- Explore (explore.html): 7 tourist attractions with photos, local culture, 10 activities, external link to the official tourism website
- Transport (transport.html): ferry, flights and Athens metro/bus, with sample schedule times
- About (about.html): bio, technical and soft skills, contact details, profile picture
- Contact (contact.html): enquiry form with validation and a thank-you message after submitting

## Features

- Moving background image of Greece (CSS animation) with a light-blue overlay and animated waves
- Consistent navigation menu and footer on every page
- Scroll animations, hover effects, flip cards and animated number counters
- Tabbed transport schedule
- Contact form with different input types, required fields and a phone number pattern
- Responsive layout for phones, tablets and computers

## How to run

1. Download or clone the repository.
2. Open index.html in a web browser.
3. Use the menu to visit the other pages.

## Technologies

HTML5, CSS3 (Grid, Flexbox, animations, media queries) and a little JavaScript.
